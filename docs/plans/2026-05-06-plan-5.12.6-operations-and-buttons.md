# Plan 5.12.6 — 操作 / 工具栏按钮 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 agent 能在 BOS 扩展上加自定义操作（FormOperation,可选 inline Python 到 ServicePlugins）+ 工具栏按钮(BarButtonItem,绑操作), 列出和删除已有操作 / 按钮, 闭合"自定义按钮 + Python 脚本"高价值 demo 场景。

**Architecture(2026-05-06 重写,基于 capture 实证)：**

- **走 .NET bridge 路线**(沿用 Plan 5.12.4 v2 转换规则模式),不走 Plan 5.12.3b 的 path A 字符串模板 overlay。原因:capture 实证表明 BOS DCXML 是 **stateful baseline diff vs 父对象 SAL_SaleOrder**,删除一个扩展自己加的 element = 下次不再 ship 这个 element,**不存在 `<FormOperation action="remove" oid=...>` 命令式删除**。path A inject overlay 模式只能加,不能删,必须 read → DOM modify → ship 整体,这正是 bridge 反序列化 + 修改 + 序列化的天然工作流。详见 `docs/recon/2026-05-06-operations-spike.md`。
- bridge ops 是纯函数 `string xml in → string xml out`,**不持 HTTP session、不与 K/3 server 通信**。I/O 留在 TS 端:connector 用现有 `connector.getKernelXml(extId)` 拉扩展 FKERNELXML → 调 bridge op patch → 用现有 `saveExtensionRaw` HTTP wrapper 推回。
- bridge `BosContext` 用 `PatchMeta` 风格(同 5.12.4 v2):`DcxmlSerializer.DeserializeFromString(formMetadataXml)` → 拿强类型 BusinessInfo / LayoutInfo → 在 Form.FormOperations / FormAppearance.Menu.BarDataManager 集合上 add/remove → `SerializeToString` 吐回 element-level delta DCXML。
- **Python 双路径支持**:
  - 现有 `k3cloud_register_python_plugins`(FormPlugins, form 生命周期)继续工作不变
  - 新 `k3cloud_add_custom_operation` 可选参数 `pyBody` → inline 到该操作的 `ServicePlugins`(操作触发的脚本)

**Tech Stack:** TypeScript + C# .NET 4.8 + Vitest + Kingdee.BOS.Core 反射

```csharp
using System;
using System.Collections;
using System.Collections.Generic;
using System.Linq;
using Newtonsoft.Json.Linq;

namespace OpenDeploy.BosBridge
{
    /// <summary>
    /// FormOperation + BarButtonItem patch ops (Plan 5.12.6).
    ///
    /// Wire shape verified by capture req-96 / req-212 / req-117 / req-137
    /// (docs/recon/2026-05-06-operations-spike.md). DCXML is stateful baseline
    /// diff vs parent SAL_SaleOrder — these ops deserialize the extension's
    /// FKERNELXML, mutate the strongly-typed BusinessInfo / LayoutInfo collections,
    /// and serialize back the element-level delta DCXML.
    /// </summary>
    internal partial class BosContext
    {
        public object ListOperations(string xml)
        {
            var meta = DeserializeFormMetadata(xml);
            var businessInfo = GetBusinessInfo(meta);
            var layoutInfo = GetLayoutInfo(meta);

            var operations = new List<JObject>();
            var form = GetForm(businessInfo);
            if (form != null)
            {
                var formOperations = ReflectGetCollection(form, "FormOperations");
                if (formOperations != null)
                {
                    foreach (var op in formOperations)
                    {
                        var opObj = new JObject();
                        opObj["operationKey"] = (string)ReflectGet(op, "Operation");
                        opObj["operationId"] = (long?)ReflectGet(op, "OperationId");
                        opObj["operationName"] = LocaleValueToString(ReflectGet(op, "OperationName"));
                        opObj["operationObjectKey"] = ExtractOperationObjectKey(op);
                        opObj["pluginClassName"] = ExtractFirstServicePluginClassName(op);
                        opObj["hasInlineScript"] = HasInlinePython(op);
                        operations.Add(opObj);
                    }
                }
            }

            var buttons = new List<JObject>();
            if (layoutInfo != null)
            {
                foreach (var ap in WalkAppearances(layoutInfo))
                {
                    var apType = ap.GetType().Name;
                    var parentEntityKey = apType == "EntryEntityAppearance"
                        ? (string)ReflectGet(ap, "Key")
                        : null;
                    var menu = ReflectGet(ap, "Menu");
                    if (menu == null) continue;
                    var barDataManager = ReflectGet(menu, "BarDataManager");
                    if (barDataManager == null) continue;
                    var barItems = ReflectGetCollection(barDataManager, "BarItems");
                    var barLinks = ReflectGetCollection(barDataManager, "BarItemLinks");
                    if (barItems == null) continue;

                    foreach (var item in barItems)
                    {
                        if (item.GetType().Name != "BarButtonItem") continue;
                        var btn = new JObject();
                        btn["buttonKey"] = (string)ReflectGet(item, "Key");
                        btn["buttonId"] = (string)ReflectGet(item, "Id");
                        btn["caption"] = LocaleValueToString(ReflectGet(item, "Caption"));
                        btn["seq"] = (int?)ReflectGet(item, "Seq");
                        btn["parentEntityKey"] = parentEntityKey;
                        btn["boundOperationKey"] = ExtractBoundOpKey(item);
                        var linkInfo = FindBarItemLink(barLinks, (string)ReflectGet(item, "Key"));
                        btn["barItemLinkId"] = linkInfo.linkId;
                        btn["toolbarKey"] = linkInfo.parentKey;
                        buttons.Add(btn);
                    }
                }
            }

            return new { operations, toolbarButtons = buttons };
        }

        // helper: ExtractOperationObjectKey, ExtractFirstServicePluginClassName,
        // HasInlinePython, ExtractBoundOpKey, FindBarItemLink, WalkAppearances —
        // see Reflection helpers in BosContext.Reflection.cs (extend it).
    }
}
```

```csharp
public object AddCustomOperation(JObject req)
{
    var xml = (string)req["xml"] ?? throw new ArgumentException("missing xml");
    var operationKey = (string)req["operationKey"] ?? throw new ArgumentException("missing operationKey");
    if (string.IsNullOrWhiteSpace(operationKey))
        throw new ArgumentException("operationKey: cannot be empty");
    var operationName = (string)req["operationName"] ?? throw new ArgumentException("missing operationName");
    var operationParameterId = (string)req["operationParameterId"] ?? throw new ArgumentException("missing operationParameterId");
    var operationId = (long?)req["operationId"] ?? 45L; // default DoNothing
    var pluginClassName = (string)req["pluginClassName"];
    var pyBody = (string)req["pyBody"];
    var operationObjectKey = (string)req["operationObjectKey"];
    var expressValue = (string)req["expressValue"];

    var meta = DeserializeFormMetadata(xml);
    var businessInfo = GetBusinessInfo(meta);
    var form = GetForm(businessInfo) ?? throw new InvalidOperationException("Form node missing");

    var formOperations = ReflectGetOrCreateCollection(form, "FormOperations");
    foreach (var existing in formOperations)
    {
        if ((string)ReflectGet(existing, "Operation") == operationKey)
            throw new InvalidOperationException($"操作 {operationKey} 已存在");
    }

    var op = ReflectCreate("Kingdee.BOS.Core.Metadata.FormElement.FormOperation");
    ReflectSet(op, "Id", operationKey);
    ReflectSet(op, "Operation", operationKey);
    ReflectSet(op, "OperationId", operationId);
    ReflectSetLocaleValue(op, "OperationName", operationName);
    ReflectSet(op, "LoadKeys", "[]");

    var parameter = ReflectCreate("Kingdee.BOS.Core.Metadata.FormElement.OperationParameter");
    ReflectSet(parameter, "Id", operationParameterId);
    if (!string.IsNullOrEmpty(operationObjectKey))
        ReflectSet(parameter, "OperationObjectKey", operationObjectKey);
    if (!string.IsNullOrEmpty(expressValue))
        ReflectSet(parameter, "ExpressValue", expressValue);
    ReflectSet(op, "Parmeter", parameter); // typo preserved

    if (!string.IsNullOrEmpty(pluginClassName))
    {
        var servicePlugins = ReflectGetOrCreateCollection(op, "ServicePlugins");
        var plugin = ReflectCreate("Kingdee.BOS.Core.Metadata.FormElement.PlugIn");
        ReflectSet(plugin, "ClassName", pluginClassName);
        ReflectSet(plugin, "PlugInType", 1); // 1=Python
        if (!string.IsNullOrEmpty(pyBody))
            ReflectSet(plugin, "PyScript", pyBody);
        servicePlugins.Add(plugin);
    }

    formOperations.Add(op);

    return new { xml = SerializeFormMetadata(meta) };
}
```

```csharp
public object RemoveOperation(JObject req)
{
    var xml = (string)req["xml"] ?? throw new ArgumentException("missing xml");
    var operationKey = (string)req["operationKey"] ?? throw new ArgumentException("missing operationKey");

    var meta = DeserializeFormMetadata(xml);
    var businessInfo = GetBusinessInfo(meta);
    var form = GetForm(businessInfo) ?? throw new InvalidOperationException("Form node missing");

    var formOperations = ReflectGetCollection(form, "FormOperations")
        ?? throw new InvalidOperationException($"操作 {operationKey} 不存在");

    object target = null;
    foreach (var op in formOperations)
    {
        if ((string)ReflectGet(op, "Operation") == operationKey) { target = op; break; }
    }
    if (target == null) throw new InvalidOperationException($"操作 {operationKey} 不存在");

    formOperations.Remove(target);

    return new { xml = SerializeFormMetadata(meta) };
}
```

```csharp
public object AddToolbarButton(JObject req)
{
    var xml = (string)req["xml"] ?? throw new ArgumentException("missing xml");
    var target = req["target"] as JObject ?? throw new ArgumentException("missing target");
    var kind = (string)target["kind"] ?? throw new ArgumentException("target.kind required");
    var entityKey = (string)target["entityKey"]; // null when kind=form

    var buttonKey = (string)req["buttonKey"] ?? throw new ArgumentException("missing buttonKey");
    var buttonId = (string)req["buttonId"] ?? throw new ArgumentException("missing buttonId");
    var caption = (string)req["caption"] ?? throw new ArgumentException("missing caption");
    var seq = (int?)req["seq"] ?? 1;
    var boundOpKey = (string)req["boundOperationKey"] ?? throw new ArgumentException("missing boundOperationKey");
    var boundOpName = (string)req["boundOperationName"] ?? boundOpKey;
    var toolbarKey = (string)req["toolbarKey"] ?? throw new ArgumentException("missing toolbarKey");
    var barDataManagerId = (string)req["barDataManagerId"] ?? throw new ArgumentException("missing barDataManagerId");
    var formBusinessServiceId = (string)req["formBusinessServiceId"] ?? throw new ArgumentException("missing formBusinessServiceId");
    var barItemLinkId = (string)req["barItemLinkId"] ?? throw new ArgumentException("missing barItemLinkId");

    var meta = DeserializeFormMetadata(xml);
    var businessInfo = GetBusinessInfo(meta);
    var layoutInfo = GetLayoutInfo(meta);

    // pre-flight: bound op must exist
    var form = GetForm(businessInfo);
    var formOps = form != null ? ReflectGetCollection(form, "FormOperations") : null;
    var foundOp = false;
    if (formOps != null)
        foreach (var op in formOps)
            if ((string)ReflectGet(op, "Operation") == boundOpKey) { foundOp = true; break; }
    if (!foundOp)
        throw new InvalidOperationException($"boundOperationKey \"{boundOpKey}\" 不存在");

    // resolve target appearance
    object appearance = kind == "form"
        ? FindFormAppearance(layoutInfo)
        : FindEntryEntityAppearanceByKey(layoutInfo, entityKey);
    if (appearance == null)
        throw new InvalidOperationException(kind == "form"
            ? "FormAppearance 未找到 — form 顶层 layout 不存在"
            : $"entityKey \"{entityKey}\" 对应的 EntryEntityAppearance 未找到");

    // pre-flight: dup buttonKey check (cross all appearances)
    foreach (var ap in WalkAppearances(layoutInfo))
    {
        var menu = ReflectGet(ap, "Menu");
        if (menu == null) continue;
        var bdm = ReflectGet(menu, "BarDataManager");
        if (bdm == null) continue;
        var items = ReflectGetCollection(bdm, "BarItems");
        if (items == null) continue;
        foreach (var item in items)
            if (item.GetType().Name == "BarButtonItem"
                && (string)ReflectGet(item, "Key") == buttonKey)
                throw new InvalidOperationException($"按钮 {buttonKey} 已存在");
    }

    // get-or-create Menu / BarDataManager / BarItems / BarItemLinks
    var menuObj = ReflectGetOrCreate(appearance, "Menu", "Kingdee.BOS.Core.Metadata.FormElement.Menu");
    var barDataManager = ReflectGet(menuObj, "BarDataManager")
        ?? ReflectCreateAndSet(menuObj, "BarDataManager",
                "Kingdee.BOS.Core.Metadata.FormElement.BarDataManager");
    if (string.IsNullOrEmpty((string)ReflectGet(barDataManager, "Id")))
        ReflectSet(barDataManager, "Id", barDataManagerId);

    var barItems = ReflectGetOrCreateCollection(barDataManager, "BarItems");
    var barItemLinks = ReflectGetOrCreateCollection(barDataManager, "BarItemLinks");

    // build BarButtonItem
    var btn = ReflectCreate("Kingdee.BOS.Core.Metadata.FormElement.BarButtonItem");
    ReflectSet(btn, "Key", buttonKey);
    ReflectSet(btn, "Id", buttonId);
    ReflectSet(btn, "Seq", seq);
    ReflectSet(btn, "Description", "按钮");
    ReflectSet(btn, "IsShowTitle", true);
    ReflectSetLocaleValue(btn, "Caption", caption);

    // ClickActions
    var clickActions = ReflectGetOrCreateCollection(btn, "ClickActions");
    var fbs = ReflectCreate("Kingdee.BOS.Core.BusinessFlow.FormBusinessService");
    ReflectSet(fbs, "Id", formBusinessServiceId);
    ReflectSet(fbs, "ActionId", 23);
    ReflectSet(fbs, "Description", $"调用表单操作--{boundOpName}");
    ReflectSet(fbs, "Parameters", $"[\"{boundOpKey}\"]");
    clickActions.Add(fbs);

    barItems.Add(btn);

    // BarItemLink
    var link = ReflectCreate("Kingdee.BOS.Core.Metadata.FormElement.BarItemLink");
    ReflectSet(link, "Id", barItemLinkId);
    ReflectSet(link, "BarItemKey", buttonKey);
    ReflectSet(link, "ParentKey", toolbarKey);
    barItemLinks.Add(link);

    return new { xml = SerializeFormMetadata(meta) };
}
```

```csharp
public object RemoveToolbarButton(JObject req)
{
    var xml = (string)req["xml"] ?? throw new ArgumentException("missing xml");
    var buttonKey = (string)req["buttonKey"] ?? throw new ArgumentException("missing buttonKey");

    var meta = DeserializeFormMetadata(xml);
    var layoutInfo = GetLayoutInfo(meta);
    if (layoutInfo == null)
        throw new InvalidOperationException($"按钮 {buttonKey} 不存在");

    var found = false;
    foreach (var ap in WalkAppearances(layoutInfo))
    {
        var menu = ReflectGet(ap, "Menu");
        if (menu == null) continue;
        var bdm = ReflectGet(menu, "BarDataManager");
        if (bdm == null) continue;
        var barItems = ReflectGetCollection(bdm, "BarItems");
        var barItemLinks = ReflectGetCollection(bdm, "BarItemLinks");
        if (barItems == null) continue;

        object targetBtn = null;
        foreach (var item in barItems)
        {
            if (item.GetType().Name == "BarButtonItem"
                && (string)ReflectGet(item, "Key") == buttonKey)
            { targetBtn = item; break; }
        }
        if (targetBtn != null)
        {
            barItems.Remove(targetBtn);
            // remove link too
            if (barItemLinks != null)
            {
                object targetLink = null;
                foreach (var link in barItemLinks)
                    if ((string)ReflectGet(link, "BarItemKey") == buttonKey)
                    { targetLink = link; break; }
                if (targetLink != null) barItemLinks.Remove(targetLink);
            }
            found = true;
            break;
        }
    }
    if (!found) throw new InvalidOperationException($"按钮 {buttonKey} 不存在");

    return new { xml = SerializeFormMetadata(meta) };
}
```

```typescript
async addCustomOperation(args: {
  extensionFid: string;
  operationKey: string;
  operationName: string;
  operationParameterId: string;
  operationId?: number; // default 45
  pluginClassName?: string;
  pyBody?: string;
  operationObjectKey?: string;
  expressValue?: string;
}): Promise<{ operationKey: string }> {
  const session = this.requireSession();
  const ext = await this.getObject(args.extensionFid);
  if (!ext) throw new Error(`扩展 ${args.extensionFid} 不存在`);

  const extXml = await this.getKernelXml(args.extensionFid);
  if (!extXml) throw new Error(`扩展 ${args.extensionFid} 无 FKERNELXML`);

  const { xml: patchedXml } = await bridgeClient.send<{ xml: string }>('add_custom_operation', {
    xml: extXml,
    operationKey: args.operationKey,
    operationName: args.operationName,
    operationParameterId: args.operationParameterId,
    operationId: args.operationId ?? 45,
    pluginClassName: args.pluginClassName,
    pyBody: args.pyBody,
    operationObjectKey: args.operationObjectKey,
    expressValue: args.expressValue,
  });

  const meta = await this.buildSaveExtensionRawMeta(session, args.extensionFid, ext);
  const result = await saveExtensionRaw(session, meta, patchedXml);
  if (!result.isSuccess) {
    throw new Error(`添加自定义操作失败:${result.messageTitle ?? ''} ${result.messageDetail ?? '<no detail>'}`);
  }
  return { operationKey: args.operationKey };
}
```

```typescript
import { randomUUID } from 'node:crypto';
import { z } from 'zod';
import type { ToolRegistry } from './tools';
import type { K3CloudConnector } from '@main/erp/k3cloud/connector';

function compactGuid(): string {
  return randomUUID().replace(/-/g, '');
}

const C_IDENT_RE = /^[A-Za-z_][A-Za-z0-9_]*$/;

export function registerOperationTools(
  reg: ToolRegistry,
  connector: K3CloudConnector,
  _projectId: string,
): void {
  reg.add({
    name: 'k3cloud_list_operations',
    description:
      '列出 BOS 扩展上的自定义操作(FormOperation)和工具栏按钮(BarButtonItem)。' +
      '操作是「按下按钮要做什么」的逻辑实体,按钮是「在哪个工具栏显示的入口」。' +
      '返回 { operations[], toolbarButtons[] };toolbarButtons[i].boundOperationKey 指向触发的操作;' +
      'operations[i].hasInlineScript=true 表示该操作的 ServicePlugins 已 inline Python。',
    parallelSafe: true,
    inputSchema: z.object({
      extensionFid: z.string().describe('BOS 扩展对象的 FID'),
    }),
    run: async ({ extensionFid }) => connector.listOperations(extensionFid),
  });

  reg.add({
    name: 'k3cloud_add_custom_operation',
    description:
      '在 BOS 扩展上加一个自定义操作。可选 pluginClassName + pyBody 参数 → Python 源码 inline 到该操作的 ServicePlugins,点按钮就跑这段 Python。' +
      '不传 pyBody → 操作壳子(用户可后续走 register_python_plugins 走 FormPlugins/AfterDoOperation 路径)。' +
      'OperationId 默认 45=DoNothing(自定义);也可指定其他内置 ID 做内置操作变体(如 2=Copy,加 expressValue 自定义参数)。' +
      '同一扩展 operationKey 必须唯一,失败显式报错。',
    parallelSafe: false,
    inputSchema: z.object({
      extensionFid: z.string(),
      operationKey: z.string().regex(C_IDENT_RE, 'operationKey 必须是 C 标识符'),
      operationName: z.string().describe('操作显示名称,中文'),
      operationId: z.number().int().optional().describe('默认 45=DoNothing 自定义;指定内置 id 时是该操作的变体'),
      pluginClassName: z.string().optional()
        .describe('Python 插件简短名(BOS Designer 服务插件列表里的标识),与 pyBody 配对使用'),
      pyBody: z.string().optional()
        .describe('IronPython 2.7 源码;含必要 import + 类定义。inline 到 ServicePlugins'),
      operationObjectKey: z.string().optional().describe('绑到某 entry,可选'),
      expressValue: z.string().optional().describe('OperationParameter.ExpressValue 内置 op 变体的参数;v0.1 大多数场景留空'),
    }).refine(
      (d) => !(d.pyBody && !d.pluginClassName),
      { message: '指定 pyBody 时必须同时指定 pluginClassName' },
    ),
    run: async (args) => connector.addCustomOperation({
      extensionFid: args.extensionFid,
      operationKey: args.operationKey,
      operationName: args.operationName,
      operationParameterId: randomUUID(),
      operationId: args.operationId,
      pluginClassName: args.pluginClassName,
      pyBody: args.pyBody,
      operationObjectKey: args.operationObjectKey,
      expressValue: args.expressValue,
    }),
  });

  reg.add({
    name: 'k3cloud_delete_operation',
    description:
      '按 operationKey 删除自定义操作。注意:不连带删除按钮 — 引用此操作的按钮会变「无效引用」。' +
      '调用前先 list_operations 检查 toolbarButtons[].boundOperationKey,有引用先 delete_toolbar_button。',
    parallelSafe: false,
    inputSchema: z.object({
      extensionFid: z.string(),
      operationKey: z.string().regex(C_IDENT_RE),
    }),
    run: async ({ extensionFid, operationKey }) => {
      await connector.removeOperation(extensionFid, operationKey);
      return { ok: true, operationKey };
    },
  });

  reg.add({
    name: 'k3cloud_add_toolbar_button',
    description:
      '在 BOS 扩展某个位置的工具栏加一个按钮,绑已存在的 FormOperation。' +
      'target.kind="form" 加到 form 顶层主工具栏;target.kind="entry" 加到指定 entry 的工具栏(必传 entityKey)。' +
      'toolbarKey 是父级 ToolBar 的 Key,从 list_operations 取现有 toolbar 借用即可;若 list 拿不到 toolbar(entry 还没初始化工具栏),提示用户在 BOS Designer 手工加临时按钮初始化。' +
      'boundOperationKey 必须先 add_custom_operation 创出来。同一扩展 buttonKey 必须唯一。',
    parallelSafe: false,
    inputSchema: z.object({
      extensionFid: z.string(),
      target: z.discriminatedUnion('kind', [
        z.object({ kind: z.literal('form') }),
        z.object({ kind: z.literal('entry'), entityKey: z.string() }),
      ]),
      buttonKey: z.string().regex(C_IDENT_RE),
      caption: z.string(),
      seq: z.number().int().min(1).default(1),
      boundOperationKey: z.string().regex(C_IDENT_RE),
      toolbarKey: z.string().regex(C_IDENT_RE),
    }),
    run: async (args) => {
      // 内部读 list_operations 拿 boundOperationName(给 ClickActions Description 用)
      const list = await connector.listOperations(args.extensionFid);
      const op = list.operations.find((o) => o.operationKey === args.boundOperationKey);
      if (!op) {
        throw new Error(`boundOperationKey "${args.boundOperationKey}" 不存在;请先 add_custom_operation`);
      }
      return await connector.addToolbarButton({
        extensionFid: args.extensionFid,
        target: args.target,
        buttonKey: args.buttonKey,
        buttonId: compactGuid(),
        caption: args.caption,
        seq: args.seq,
        boundOperationKey: args.boundOperationKey,
        boundOperationName: op.operationName,
        toolbarKey: args.toolbarKey,
        barDataManagerId: randomUUID(),
        formBusinessServiceId: randomUUID(),
        barItemLinkId: randomUUID(),
      });
    },
  });

  reg.add({
    name: 'k3cloud_delete_toolbar_button',
    description: '按 buttonKey 删除工具栏按钮(连带删 BarItemLink)。',
    parallelSafe: false,
    inputSchema: z.object({
      extensionFid: z.string(),
      buttonKey: z.string().regex(C_IDENT_RE),
    }),
    run: async ({ extensionFid, buttonKey }) => {
      await connector.removeToolbarButton(extensionFid, buttonKey);
      return { ok: true, buttonKey };
    },
  });
}
```

### Task 5.1: 加操作 / 按钮纪律到 erp-rules/k3cloud.md

**Files:**

- [ ] **Step 1: 在工具列表段后加新工具简介 + 使用纪律**

```markdown
## BOS 操作 / 工具栏按钮工具

- `k3cloud_list_operations` — 列扩展自定义操作 + 按钮(parallelSafe)
- `k3cloud_add_custom_operation` — 加 FormOperation;**可选 pyBody → 直接 inline Python 到该操作**
- `k3cloud_delete_operation` — 按 key 删操作(不连带删按钮)
- `k3cloud_add_toolbar_button` — 加按钮(form 顶层 / entry 级),绑已存在操作
- `k3cloud_delete_toolbar_button` — 按 key 删按钮 + BarItemLink

### Python 挂载点 — 两条路径

K/3 BOS 把 Python 源码 inline 到 form 元数据里,有两个挂载点:

1. **ServicePlugins**(操作的服务插件)— `add_custom_operation` 传 `pyBody` + `pluginClassName` 时用;**点按钮就跑这段脚本**;每个操作独立一个脚本块。**单按钮单一逻辑首选**(如:点了打折 / 点了反审)。
2. **FormPlugins**(form 生命周期)— `register_python_plugins` 工具,Python 监听 OnInitialize / AfterDoOperation 等表单事件;通过 operationKey 路由实现"点不同按钮跑不同分支"。**跨多按钮共享逻辑首选**(如:任何按钮触发都先校验信用额度)。

agent 按场景选挂载点。**不要两个都挂同一逻辑**(会执行两次)。

### 使用纪律

1. **加按钮 = 至少 2 步**:add_custom_operation(可同时 inline pyBody)→ add_toolbar_button(绑前一步 operationKey)。如果场景需要 form 生命周期事件,先 register_python_plugins。
2. **toolbarKey 先 list_operations 取**:不能凭空起 ToolBar key。entry 没初始化工具栏时 list 拿不到 — 提示用户在 BOS Designer 手工加临时按钮初始化后再删,或当作 v0.1 限制说明。
3. **删操作前先看引用**:删 operation 不会自动删按钮;list 检查 boundOperationKey 引用,有先删按钮。
4. **OperationId=45 是默认**:自定义操作 99% 用 45=DoNothing。要做内置操作变体(如 2=Copy + 自定义 expressValue 参数)才显式传 operationId。
5. **闭环反查**:add_* / delete_* 后必须 list_operations 验证。BOS 客户端缓存,新按钮可能要重启客户端登出登回才见(prompt 已沉淀)。
```
