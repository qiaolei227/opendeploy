**Goal:** 让 agent 能告诉客户"X 单据可以下推到哪些目标单"以及"具体某条规则是怎么映射的"——5.12.4 范围只读，不做创建/修改（留 v0.2）。

**Tech Stack:** TypeScript / Vitest（沿用 Plan 5.x 栈，无新增）

**Scope 红线（本 plan 不做）：**

## 数据 shape 速查（实证）

### `ConvertService.GetAllPaths()` 返回（173 KB JSON 数组）

```json
[
  {
    "SourceFormId": "SAL_SaleOrder",
    "TargetFormId": "SAL_OUTSTOCK",
    "SourceFormName": [{"Key": 2052, "Value": "销售订单"}],
    "TargetFormName": [{"Key": 2052, "Value": "销售出库单"}],
    "SourceBusinessInfo": null,
    "TargetBusinessInfo": null,
    "SourceFormMetadata": null,
    "TargetFormMetadata": null
  }
  // ... 数百条
]
```

**注意**：GetAllPaths 不告诉 ruleId，只告诉路径。**ruleId 命名约定** = `<SourceShort>-<TargetShort>`（如 `SaleOrder-OutStock`，去掉模块前缀 SAL_ + 用 PascalCase）—— 这是 BOS 内部约定，**describe 工具的 ruleId 入参由 agent 从 list 结果推断或用户直接给**。

实际可能不只一条规则映射同一对路径（默认 + 备用），需要单独端点查"按 source+target 列规则" — 后续探（5.12.4 v1.1 扩）。

### `ConvertService.GetConvertRule(ruleId)` 返回（240 KB JSON 对象）

顶层包装（28 字段，元数据级）：
```
{ Id, ModelTypeId(=790), Name, BaseObjectId, SourceFormId, DevType, HasExtends,
  InheritPath, IsKingdeeElement, SubSystemId, Version, MainVersion, RunTime,
  ISV, PackageId, ... , Rule }
```

`Rule` 是 `ConvertRuleElement`（24 字段 + Policies 数组）：
```
{ ___InstClassType__: "...ConvertRuleElement,Kingdee.BOS.Core",
  SourceFormId, TargetFormId, Status, IsDefault, Invisible, IsRandom, FreePush,
  CheckLinkSet, Formula, PushRunCondition, PushRunConditionExt, ConvertType,
  Policies: [<10 个 Policy>],
  EnabledTakeFailTip, ExtCtrl, ... }
```

10 个 Policy 在 `Rule.Policies` 数组里（顺序由 OrderNo 决定）：

| Index | Policy 类 | OrderNo | 关键字段 |
|---:|---|---:|---|
| 0 | DefaultConvertPolicyElement | 3 | SourceEntryKey / TargetEntryKey / FieldMaps[N] |
| 1 | ConvertGroupByPolicyElement | 4 | GroupByMode (int) / GroupByField (CSV) / GroupByField2 / GroupByField3 / GroupByFormula |
| 2 | ConvertFilterPolicyElement | 5 | AlertMessage (LocaleValue) / CustFilter (IronPython) / TargetOrgBDFilterList |
| 3 | ConvertPlugInPolicyElement | 6 | Plugs[N] → ClassName |
| 4 | ConvertFormBusinessPolicyElement | 7 | FormBusinessList |
| 5 | LinkEntityPolicyElement | 1 | ControlEntityKey / FieldMaps[M] |
| 6 | BillTypeMapPolicyElement | 2 | BillTypeMaps[K] → SourceBillTypeId / TargetBillTypeId (GUID) |
| 7 | ConvertOrderByPolicyElement | 5 | OrderByField |
| 8 | ConvertAttachmentPolicyElement | 8 | EnabledHeader / EnabledEntry / EnabledSubEntry / Deduplication |
| 9 | ConvertTailDiffPolicyElement | 10 | IsEnabled / MarkFieldKey / RecordFieldKey / FieldMaps / BaseFieldMaps |

每个 FieldMap（DefaultConvertPolicy 实证 273 条）：
```
{ ___InstClassType__, TargetFieldKey, TargetFieldName, SourceFieldKey, SourceFieldName,
  ValueConvertMode (int enum), Formula (string|null), FormulaDesc (string|null),
  IsFilter (bool), OnlyAgain (bool), ... 6 more bools, Id, Key, ElementType }
```

### Enum 反映射表

**`ValueConvertMode`**（int → string，源自 `Kingdee.BOS.Core.Metadata.ConvertElement.ValueConvertMode` 枚举）：

| int | string | 含义 |
|---:|---|---|
| 0 | Auto | 自动（源字段类型决定） |
| 1 | Sum | 求和 |
| 2 | Average | 平均 |
| 3 | Count | 计数 |
| 4 | Max | 最大值 |
| 5 | Min | 最小值 |
| 6 | Formula | 公式 |
| 7 | Join | 拼接 |
| 8 | SumFormula | 先求和再用公式 |

**`GroupByMode`**（int → string）：

| int | string |
|---:|---|
| 0 | None |
| 1 | OneToOne |
| 2 | GroupByField |
| 3 | GroupByFormula |

（其他 enum 反映射在实施时按需补；以 Kingdee.BOS.Core decompile 为准）

## 摘要器策略（避免 240 KB token 溢出）

`kingdee_describe_convert_rule` 返回结构：

```typescript
interface ConvertRuleSummary {
  ruleId: string;
  displayName: string;
  sourceFormId: string;
  targetFormId: string;
  isDefault: boolean;
  isActive: boolean;          // = Status
  invisible: boolean;
  convertType: 0 | 1;         // 0=标准, 1=反向勾稽
  pushRunCondition: string | null;

  defaultConvert: {
    sourceEntry: string;
    targetEntry: string;
    fieldMapCount: number;
    formulaMaps: Array<{
      target: string;
      mode: string;             // 反映射后的 string 名
      formula: string | null;
      formulaDesc: string | null;
    }>;
    aggregateMaps: Array<{ target: string; mode: string }>;  // Sum/Avg/Count/Max/Min/Join/SumFormula
  };

  groupBy: {
    mode: string;               // None/OneToOne/GroupByField/GroupByFormula
    fields: string[];           // GroupByField 拆 CSV
    formula: string | null;
  };

  filter: {
    alertMessage: string | null;
    customFilter: string | null;
  };

  plugins: string[];            // ClassName 列表

  billTypeMaps: Array<{ source: string; target: string }> | null;  // GUID 直出，N>0 才有

  linkEntity: { controlEntity: string; fieldMapCount: number } | null;

  attachment: {
    header: boolean;
    entry: boolean;
    subEntry: boolean;
    deduplication: boolean;
  };

  tailDiff: { enabled: boolean; markField: string | null } | null;
}
```

**关键过滤规则**：
- `formulaMaps` 只列 `ValueConvertMode === 6` 的 FieldMap（含 IronPython 公式）
- `aggregateMaps` 列 mode ∈ {Sum, Average, Count, Max, Min, Join, SumFormula}
- 默认 Auto 映射不展开，只给 `fieldMapCount` 总数
- agent 想看完整 FieldMap dump 时，未来可加可选参数 `verbose: true` 直透 raw JSON（v0.2）

预估摘要体积：`SaleOrder-OutStock` 240 KB → 摘要后 ~3 KB（9 个 formulaMap + 1 个 GroupBy + 6 个 plugins + 8 个 BillTypeMap）。
