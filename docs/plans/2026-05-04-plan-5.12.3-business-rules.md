# Plan 5.12.3 — BOS 业务规则（route C validate-and-retry）

> **Status**: Design — 2026-05-04 完稿，等用户审 spec 后转 writing-plans。
> **Master plan**: `2026-04-25-plan-5.12-bos-tool-surface-expansion.md`
> **依赖**: 5.12.1 字段扩展（已完成）+ 5.12.4 v2 .NET bridge spike（已完成 8 ops）

---

## Goal

让 agent 能在 BOS 扩展上加业务规则，覆盖实施顾问 80%+ 的"字段联动 / 自动取值 / 校验"场景。LLM 直出 IronPython（仅 Calculate）或 typed 字段映射对象（其他 5 个 ActionId），工具内部跑校验，失败 retry 1 次给精确反馈。

## Architecture（与 5.12.4 v2 对齐）

写入路径走 .NET bridge（`bos-bridge/`）→ BOS 自己生成 DCXML diff → SaveForIDEV9 推服务端。**不走 SQL 直改 FKERNELXML**，避免缓存陷阱（memory `bos_metadata_cache_invalidation`）。

LLM input → agent 工具校验 → bridge serialize service node → bridge build DCXML diff → SaveForIDEV9 → BOS 服务端 reload。

### 两层挂载点（都做）

- **实体级 EntityServiceRule** — 挂在 head/entry 上，有 `PreCondition` + `whenTrue/whenFalse` 分支
- **字段级 UpdateActions** — 挂在单个 Field 上，无 PreCondition，通过 8 个 `Raise<Event>` 子元素控制触发时机

工具通过 `mountPoint` 参数区分挂载方式：

```typescript
type MountPoint =
  | { kind: 'entity'; entityKey: string;
      preCondition?: string;
      branch?: 'whenTrue' | 'whenFalse';
      description?: string }
  | { kind: 'field'; fieldKey: string;
      disabledEvents?: RaiseEvent[] };

type RaiseEvent =
  | 'RaiseValueChanged' | 'RaiseInitialized' | 'RaiseItemAdded'
  | 'RaiseItemReset'    | 'RaiseItemRemoved' | 'RaiseReset'
  | 'RaiseSelectRowChanged' | 'RaiseSelectRowExtChanged';
```

- 其他 16 个 Tier 4-5 ActionId（GetDiscount=43 / UpdateCredit=64 / SalLimitDownPrice=49000 / 等）— 客户报需求再加，留 v0.2

## Validator 实现（route C 分级）

### Calculate (ActionId=2) — 完整 AST 校验

输入：`actions: string[]` + `preCondition?: string`

校验步骤：
1. **IronPython 子集解析** — 用 `python-ast`（Python 2.7 兼容子集）解析每个赋值字符串
2. **赋值结构校验** — 每条必须是 `<TargetField> = <Expression>` 形态；表达式不能裸（`FQty * FPrice` 不带等号）
3. **字段引用查 schema** — 抽出 `F<key>` / `F<key>.F<prop>` / `GetFieldValue("Fxxx")`，每个字段 key 必须在父对象 schema 里存在
4. **函数调用白名单** — 抽出所有 `Foo(...)` 调用，对照 16 FuncDefine 白名单（`business-rules-corrected.md` §2.1）
5. **禁止模式** — 正则匹配 SQL 风格函数（`IIF / CONCAT / DATEADD / ISNULL / DATEDIFF / LEN / ROUND / SUBSTR / UPPER / LOWER`）+ Python 3 语法（`print(` / `f"` / `async def` / `await`）+ 危险 import（`os / sys / subprocess / socket`）

retry 反馈格式（精确到行号 + 建议）：
```
错误 1（第 1 条 action，"F金额 = ROUND(F数量 * F单价, 2)"）：
  - ROUND() 不存在（这是 SQL 风格函数）。Python 内置 round() 全小写。
错误 2（第 2 条 action，"F税额 = GetCurrentTime()"）：
  - GetCurrentTime() 不存在。可选：GetTime() 或 GetDate()。
```

retry 上限：1 次（第 2 次失败硬错给用户）。

### 特化 ActionId (3 / 42 / 67 / 70) — schema 字段查存在

输入：typed 字段映射对象（如 `{ FMaterialKey: 'FMaterialId', FPriceKey: 'FPrice', ... }`）

校验步骤：
1. **TypeScript 类型化** — JSON schema 严格校验输入键集
2. **字段引用查 schema** — 每个 field-key value 必须在父对象 schema 里存在
3. **Filter 表达式**（仅 InvMinusCheck）— 跑 IronPython 子集解析（同 Calculate step 1-3，不跑 step 4-5 因为 filter 不是赋值）

retry 反馈：
```
错误：FPriceKey 指向 'FCustomPrice'，但父对象 SAL_SaleOrder 没有此字段。
可选字段：FPrice / FTaxPrice / FUpPrice / FLimitDownPrice / FStdPrice / ...
```

### CallBillFunction (ActionId=23) — className 白名单

输入：`className: string` + `args: string[]`

校验步骤：
1. className 必须匹配通过 `k3cloud_register_plugin` 注册的 Python 插件类名之一
2. args 数组每条必须是合法字符串字面量

retry 反馈：
```
错误：className "MyPriceCalc" 在当前扩展未注册。
当前已注册的 Python 插件类名：CreditGuard / DiscountAuto / ...（来自 list_extension_plugins）
```
