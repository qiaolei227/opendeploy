# Plan 5.12.3a — 工具改名 + 业务规则 Tier B 实证 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成两件起手前置：1) 全局把 33 个 `kingdee_*` 工具改名 `k3cloud_*` 对齐架构命名；2) 通过 capture proxy 实证 5 个非-Calculate ActionId 的 SaveForIDEV9 wire 形态，把发现固化到 skills 文档。Plan 5.12.3b（实施）需要这两份产出作为输入。

**Architecture:**
- Phase 0 — TypeScript 重命名 + 测试断言更新 + system prompt 引用更新；不改运行时行为
- Phase 1 — 复用现有 `scripts/bos-recon/capture-proxy.ts` + `decode-capture.ts` HTTP 代理捕获 BOS Designer 的 SaveForIDEV9 调用 → 解码 base64+zlib → 抽 DCXML → 文档化每个 ActionId 的 service 节点 schema

**Tech Stack:** TypeScript + Vitest + 已有 `scripts/bos-recon/` capture 工具链
